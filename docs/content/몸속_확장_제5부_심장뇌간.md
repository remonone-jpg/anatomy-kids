# 몸속 확장 — 제5부 (카테고리 20 확장: 심장·뇌·간)

제4부에서 정의한 신규 12개 카테고리를 심장·뇌·간에 적용.
각 장기 기존 8편 + 신규 12편 = 20편.
집필 원칙은 제4부와 동일: 3~4문장, 확립된 사실, 질병 조언 금지,
기존 8편과 중복 금지, research는 단정 금지.

⚠️ 이 문서의 내용은 **웹 검증 전 초안**입니다. 전 장기 작성 완료 후
중간·주의 항목(연도, 최신 연구, 어원)을 일괄 검증할 예정입니다.

- 아침 혈압 급상승(morning surge) — 확립으로 판단하나 재확인
- 심근세포 평생 교체율(1% 미만/년, 2009 Bergmann 연구) — 수치 미기재했으나 "거의 교체되지 않음" 표현 적정성 확인
- 하트 기호 유래 — 정설 없음으로 서술함. 이 서술 자체가 적절한지 확인
- 제브라피시 심장 재생 — 확립
- 내수용감각과 감정 인식 연관 — "연구들이 있습니다"로 완화 서술

**뇌**
- 시교차상핵 = 중앙 시계 — 확립
- 성인 해마 신경신생 — **논쟁 중인 주제**. 2018년 상반된 논문 2편 발표됨. 현재 서술이 충분히 완화되어 있는지 확인 필요
- 아교세포 : 신경세포 비율 — 과거 10:1 통설이 1:1 안팎으로 수정됨. 현재 서술("비슷하거나 더 많은")이 최신 견해와 맞는지 확인
- 뇌 지방 비율 60% — 건조중량 기준 여부 확인 필요
- 우주비행사 뇌 위치 변화·SANS — 확립하되 최신 상태 확인
- 예쁜꼬마선충 302개 뉴런 — 확립
- 초파리 커넥톰 완성 시점 — **연도 확인 필요**

**간**
- 간 자체 일주기 시계, 식사 시간 동조 — 확립

- 프로메테우스 신화 — 이전에 "근거 불명확"으로 제외했던 항목을 여기서는
  "옛사람이 재생력을 알았는지 확인되지 않았다"는 단서와 함께 문화 항목으로
  포함함. 일관성 판단 필요

- 우주비행 간 지방대사 변화 — 동물 실험 한정임을 명시함. 확인
