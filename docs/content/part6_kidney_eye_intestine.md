# 몸속 확장 — 제6부 (카테고리 20 확장: 콩팥·눈·장)

제4부에서 정의한 신규 12개 카테고리를 콩팥·눈·장에 적용.
각 장기 기존 8편 + 신규 12편 = 20편.
집필 원칙은 제4부와 동일.

⚠️ 웹 검증 전 초안. 문서 끝의 검증 대기 항목 참조.

## 검증 대기 항목

**콩팥**
- 야간 항이뇨호르몬 상승, 야뇨증과 호르몬 리듬 성숙 — 확립으로 판단, 재확인
- 운동 중 신혈류 감소 — 확립
- 네프론 수 출생 시 확정, 30대 이후 GFR 감소 — 확립
- 발세포(podocyte) 여과틈새 3층 구조 — 표준 조직학
- 헨레고리 길이와 사막 동물 — 확립
- 우주 비행 중 신결석 위험 — 확립하되 최신 상태 확인
- 한랭 이뇨(cold diuresis) — 확립
- **"콩팥 = 콩 + 팥" 어원 — 통설이나 국어학적 확정 여부 확인 필요**
- **'애'가 콩팥을 포함하는지 — 창자 위주 설명이 정확한지 확인 필요**
- 이식형 인공신장 임상 단계 — **최신 상태 확인 필요**

**눈**
- 내인성 광민감 망막신경절세포(ipRGC)와 일주기 — 확립
- 전정안반사(VOR) — 확립
- 로돕신-비타민A, 야맹증 — 확립
- 노안 40대 시작 — 확립
- 척추동물 망막 역위 구조, 두족류 정위 구조 — 확립
- 눈의 다계통 독립 진화(수렴진화) — 확립. "여러 번"의 횟수는 추정치이므로 수치 미기재
- SANS(우주비행 관련 신경안구증후군) — 확립, 최신 상태 확인
- **pupil ← pupilla('작은 인형') 어원 — 확립으로 판단, 재확인**
- **'눈동자'의 '동자'가 아이(童子)에서 왔는지 — 통설, 국어학적 확인 필요**
- 인공망막·유전자치료(voretigene 등) — **최신 상태 확인 필요**
- 도약억제(saccadic suppression), 거울 실험 — 확립

**장**
- 장 일주기 리듬, 미생물총의 일중 변동 — 확립
- 운동 중 장혈류 감소, 러너의 위장 증상 — 확립
- 짧은사슬지방산이 대장세포 주 연료 — 확립
- 장상피 교체 주기 며칠, 음와 줄기세포 — 확립
- 초식/육식 장 길이 차이 — 확립
- **충수의 미생물 피난처 가설 — 가설임을 명시함. 표현 적정성 확인**
- 우주비행사 장내미생물 변화 — 확립하되 최신 상태 확인
- **'밸' 어원 및 '밸이 꼴리다' — 국어학적 확인 필요**
- 큰창자/작은창자 명명이 지름 기준 — 확립
- FMT의 재발성 클로스트리디오이데스 디피실 감염 적응증 — 확립, 최신 승인 상태 확인
- 내장통 특성(신전에 민감, 절단에 둔감, 위치 불명확) — 확립
