# 초등 교과연계 — 기관계 보기 · 순환 기관

「우리 몸의 구조와 기능」 단원을 **기관계 단위**로 다루는 신규 층.
교과서는 장기 하나가 아니라 기관계로 가르치고, 마지막에 기관계끼리
어떻게 연결되는지를 묻습니다. 지금 사이트는 장기 10개가 각각 떨어져
있어 그 연결이 없습니다.

## 전체 구조

```
초등 모드
├─ 기관계 보기 (신규 · 교과 차시 순서)
│   ├─ 뼈와 근육 (운동 기관)
│   ├─ 소화 기관
│   ├─ 호흡 기관
│   ├─ 순환 기관          ← 이 문서
│   ├─ 배설 기관
│   ├─ 감각 기관
│   └─ 기관계는 어떻게 연결될까
└─ 장기별 보기 (기존 구조 유지)
```

## 학년 표기에 대하여

「우리 몸의 구조와 기능」은 현행 교과서에서 6학년 2학기 4단원이고,
2022 개정 교육과정 단원안에는 5학년으로 제시되어 있습니다. 후자는
아직 확정 목차가 아니므로 **학년을 표기하지 않습니다.**
`curriculum: "초등 과학 · 우리 몸의 구조와 기능 · 순환 기관"`
교과서가 개정되어도 틀리지 않는 표기입니다.

## 집필 원칙

1. 교과서 용어를 그대로 쓰되 바로 풀어 준다
2. **교과서가 다루는 것을 빠뜨리지 않는다** — 기관 목록, 순서, 실험,
   다른 기관계와의 연결까지
3. 숫자에는 반드시 비교를 붙인다
4. 질병 이름은 쓰지 않는다 (어른 모드 전용 유지)
5. `{child}` 치환·받침 처리는 기존 로직 재사용
6. 시험에 나오는 것은 `summary`와 `exam`에서 반드시 짚는다

## 스키마

```ts
export type SystemContent = {
  id: string;
  curriculum: string;
  name: string;
  oneLine: string;
  intro: string;                    // 3~4문장
  organs: { name: string; role: string; organId?: string }[];  // 구성 기관
  flow: { step: string; detail: string }[];                    // 순서 — 흐름도
  terms: { word: string; mean: string }[];
  experiment: {                     // 교과서 실험
    title: string;
    goal: string;
    prepare: string[];
    steps: string[];
    result: string;
    meaning: string;                // 실험의 각 부분이 무엇에 해당하는지
  }[];
  whyQuestions: { q: string; a: string }[];
  numbers: { label: string; value: string; compare: string }[];
  tryIt: { title: string; how: string; what: string }[];
  connection: string;               // 다른 기관계와의 연결
  summary: string[];
  exam: { point: string; note: string }[];   // 시험에 자주 나오는 것
};
```
