# 몸속 콘텐츠 확장팩 v1

anatomy-kids 프로젝트용. 모든 수치는 표준 생리학 교과서 수준에서 검증했고,

## 4. 검증 노트

- 배제한 통설: 재채기 시속 160km(실측치 논란), 혈관 총길이 10만km(근거 빈약),
  평생 벗겨지는 피부 총량(수치 제각각), 얼굴 붉어질 때 위도 붉어진다(일화 수준).
- 낮춘 수치: 장 표면적 — 테니스 코트(구판 교과서) → 30~40m²(2014년 이후 계측).
  폐 스토리도 동일 기준으로 "3~5억 개 허파꽈리"만 사용.
- 손가락 주름 신경 반응: 확립된 사실. "배수로 가설"은 가설임을 본문에 명시함.
- 프로메테우스 신화는 근거 불명확하여 간 스토리에서 제외.
- 위 스토리의 보몬트-세인트 마틴(1822), 인슐린 발견(1921, 이듬해 첫 투여,
  1923년 노벨상): 표준 의학사 기록과 일치.

# 몸속 콘텐츠 확장팩 v3 — 일반 모드 심화(deepDive)

일반 모드를 책 수준으로 만드는 본편. 장기마다 고정 8개 카테고리:
구조 / 작동 원리 / 숫자로 보는 하루 / 태어나기 전과 후 / 다른 장기와의 협업 /
오해와 진실 / 발견의 역사 / 동물의 세계.
v1의 stories(4개씩)와 중복되지 않게 작성함. 전 단락 검증 완료,
근거가 약한 통설은 '오해와 진실'에서 오히려 바로잡는 소재로 사용.

## 검증 노트 (v3)

- 심장: 방실결절 지연 약 0.1초, 안정 시 심박출량 분당 약 5L(운동 시 20~25L),
  좌심실 벽 우심실의 약 3배, 태아 순환(난원공·동맥관) 출생 시 폐쇄,
  하비 1628 『심장과 혈액의 운동』 — 표준 생리학·의학사.
- 뇌: 소뇌 뉴런 약 690억(전체의 ~80%), 대뇌겉질 뉴런 사람 약 160억,
  뇌 혈류 분당 ~750mL(심박출의 15%), 게이지 1848 — 확립.
  "10% 사용설"과 "좌뇌/우뇌형 인간"은 신경과학계가 공식 부정하는 통념.
- 폐: 기도 평균 23분지, 폐포-모세혈관 장벽 1μm 미만, 계면활성제,
  날숨 산소 약 16%, 폐포 출생 후 증가 지속, 조류 일방향 호흡,
  고래 환기 효율 80~90% — 표준 호흡생리.
- 간: 문맥 75%/간동맥 25%, 혈액 보유 10%+, 요소회로(간)→배설(콩팥),
  태아기 조혈, 생리적 신생아 황달, 상어 간 체중의 ~25% — 확립.
  '디톡스 제품' 무근거는 주요 의학기관들의 일치된 입장.
- 콩팥: 네프론 수 출생 시 결정, 양수-태아뇨, EPO·레닌·비타민D 활성화,
  1954 머레이 쌍둥이 이식(1990 노벨상), 캥거루쥐 대사수 — 확립.
- 눈: 각막이 최대 굴절면, 노안=수정체 경직, 신생아 초점 20~30cm,

- 장: 지방의 림프 흡수 경로, 면역세포 ~70% 장 주변, 무균 출발과

- 피부: 수용체 분업, 무자각 수분손실 ~0.5L/일, 태지, 비타민D 경로
