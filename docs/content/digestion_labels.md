# 소화 도해 라벨 설명 — 26개 전체

기관계 도해에서 라벨을 클릭하면 뜨는 설명.
문서 `organs`에 있는 9개는 기존 role을 그대로 쓰고,
나머지 17개를 새로 작성.

## 원칙

1. 2~3문장. 초등 아이도 읽을 수 있게
2. `organs`에 있는 9개와 톤을 맞춤 (~요체)
3. 교과 범위를 넘는 것은 `beyond: true`로 표시.
   UI에서 "더 알고 싶다면" 같은 구분을 줄 수 있음
4. `organId`가 있으면 장기 상세로 이동 가능

## 스키마

```ts
export type DiagramLabel = {
  id: string;           // SVG <text> 에 붙일 id
  label: string;        // 화면에 보이는 라벨 (매칭용)
  name: string;         // 설명 제목
  desc: string;         // 설명 본문
  organId?: string;     // 있으면 장기 상세로 이동
  beyond?: boolean;     // 교과 범위 밖
};
```

## 매칭에 대한 주의

원본 SVG의 라벨 텍스트와 위 `label` 값이 정확히 일치하지 않을 수 있습니다.
특히 다음이 문제가 될 수 있습니다.

| 상황 | 예 | 처리 |
|---|---|---|
| 두 줄로 쪼개짐 | "돌창자" + "(작은창자)" | 별도 항목으로 두되 같은 설명 연결 |
| 묶음 괄호 라벨 | "침샘" 아래 3개가 묶임 | 침샘은 대표, 3개는 개별 |
| 표기 차이 | "허밑샘" vs "혀밑샘" | ★현재 SVG에 "허밑샘"으로 되어 있음 |

**★확인 필요:** 화면에 "허밑샘"으로 보이는데, 표준 표기는 **"혀밑샘"**입니다
(혀 아래에 있는 샘). SVG의 오타로 보이니 함께 수정하는 것이 좋겠습니다.

## Claude Code 프롬프트

```
소화 도해 라벨 26개 설명을 넣고 인터랙티브하게 만들어줘.
docs/content/digestion-labels.md 기준.

[0. 먼저 고칠 것]
SVG에 "허밑샘"으로 되어 있는데 표준 표기는 "혀밑샘"이야
(혀 아래에 있는 샘). digestion.svg 에서 수정해줘.

[1. 데이터]
app/i18n/school/diagrams/digestion-labels-ko.ts 신규 생성.
문서의 DiagramLabel 타입과 26개 항목 그대로.

[2. SVG에 id 부여]
매칭을 문자열 비교로 하면 깨지기 쉬우니, SVG의 <text> 요소에
DiagramLabel의 id를 직접 붙여줘.
- 어느 <text>가 어느 라벨인지 먼저 확인해서 목록으로 보여줘
- 두 줄로 쪼개진 것("돌창자" + "(작은창자)")이 어떻게 되어 있는지도

[3. 팝업]
그림 클릭 → 전체 화면 팝업
- 확대/축소, 드래그 이동
- 배경 클릭 또는 닫기 버튼으로 닫기
- 모바일에서도 동작할 것

[4. 라벨 클릭]
팝업 안에서 라벨 클릭 → 설명 표시
- 26개 전부 클릭 가능
- 클릭 가능하다는 시각적 표시 (호버 시 색 변화 등)
- 설명은 말풍선이나 하단 바에
- organId가 있으면 "자세히 보기" 링크로 장기 상세 이동
- beyond: true 인 항목은 "더 알고 싶다면" 같은 구분 표시
  (교과 범위 밖이라는 뜻이지, 숨기라는 건 아님)

[5. 어린이 모드]
어린이 모드에는 기관계 보기가 없으니 영향 없음. 확인만.

[검증]
- 26개 전부 클릭되는지
- 라벨과 설명이 올바르게 짝지어졌는지 (엉뚱한 설명이 뜨지 않는지)
- 팝업이 모바일에서 열리고 닫히는지

커밋 파일별 명시 (git add -A 금지).
```
