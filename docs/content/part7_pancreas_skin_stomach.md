# 몸속 확장 — 제7부 (카테고리 20 확장: 이자·피부·위)

제4부에서 정의한 신규 12개 카테고리를 이자·피부·위에 적용.
각 장기 기존 8편 + 신규 12편 = 20편.
**이 문서로 10개 장기 전체가 20편 체제 완성 (총 200편).**

⚠️ 웹 검증 전 초안. 문서 끝의 검증 대기 항목 참조.
