# 몸속 지식퀴즈 — 일반 모드 100문항 (1/2)

심장 · 뇌 · 폐 · 간 · 콩팥, 각 20문항.
전 문항이 deepDive 20편 / stories 4편에 실린 내용에서만 출제.
오답은 "그럴듯한 오해" 또는 "인접 사실 혼동"으로 구성.

⚠️ 검증 반영본 기준. 초파리 커넥톰(2024 완성), 눈동자 어원,
콩팥 culture 수정본이 이미 반영된 상태를 전제로 함.

## 스키마

```ts
export type KnowledgeQuizItem = {
  id: string;
  organ: OrganId;
  category: DeepDiveCategory | "stories";
  question: string;
  options: [string, string, string];
  answer: 0 | 1 | 2;
  explain: string;
};
```
