# 몸속 콘텐츠 확장팩 — 제0부 (최초 배치 moreFacts 28개)

통합본 제1부보다 먼저 전달됐던 원본 배치. 각 장기 moreFacts 배열의
"맨 앞"에 배치할 것 (그 뒤에 제1부 추가분 → 제2부 추가분 순).
이대로 넣으면 제2부 표의 개수 계산과 정확히 일치해 전 장기 10개가 됨.

## 개수 확인

심장 4, 뇌 4, 폐 3, 간 3, 콩팥 3, 눈 3, 장 3, 이자 2, 피부 3 = 28개.
제1부(+2씩, 이자만 +1) → 제2부(부족분)를 순서대로 이으면
위(stomach) 포함 10개 장기 전부 정확히 10개.

## 검증 노트

전부 앞선 배치들과 같은 기준으로 검증된 원본: 심음=판막 폐쇄음,
생쥐 심박 분당 500~700회, 흰수염고래 심장 실측(2015 해부) 범퍼카 크기,
뇌 조직 경도·수분 약 75%, 신경 전도 최대 시속 400km대, 수면 중 기억
공고화, 폐 부양성, 딸꾹질=가로막 경련, 호흡의 불수의성, 간 기능 500+,
빌리루빈 유래 변색, 간 재생, 사구체여과 180L(욕조 비유), 혈장 일 수십 회
여과, 재흡수 99%, 신생아 누액 분비 지연(생후 수 주), 안구 성장 폭 작음,
눈물막 세정, 장내미생물·발효 가스, 이자효소 전구체 활성화(장 도달 후),
식후 인슐린 분비, 지문 고유성, 표피 교체 약 4주, 입모근 반사.
