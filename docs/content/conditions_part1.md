# 임상 노트 상세 — 제1부 v2 (심장 8개 질환)

v1에서 `causes` 한 줄을 셋으로 나눈 개정본. **v1을 대체합니다.**

## 변경점

원인 안에 **바꿀 수 있는 것과 없는 것**이 섞여 있어 뭉뚱그리면
"그래서 뭘 해야 하지"가 안 잡힙니다. 셋으로 나눕니다.

- `causes` — 왜 생기나 (메커니즘, 3~4문장)
- `fixedFactors` — 바꿀 수 없는 것 (나이·가족력 등)
- `modifiableFactors` — 줄일 수 있는 것 (행동으로 이어지는 부분)

## 집필 원칙 (v1과 동일)

1. 진단 도구가 아니라 교육 자료. 독자를 진단하지 않음
2. 치료법 상세·약 이름·용량 금지
3. `seeDoctor` 필수 — 읽고 끝나지 않고 병원으로 연결
4. 불안 조장 금지. 흔한 것/드문 것을 함께 밝힘
5. 응급은 `urgent: true`로 구분
6. **`modifiableFactors`를 "노력하면 막을 수 있다"로 읽히게 쓰지 않기.**
   위험을 줄이는 것이지 없애는 것이 아니며, 관리해도 생기는 사람이 있음

## 스키마

```ts
export type ConditionDetail = {
  id: string;
  organ: OrganId;
  name: string;
  oneLine: string;
  what: string;
  symptoms: string[];
  causes: string;                 // 메커니즘
  fixedFactors: string[];         // 바꿀 수 없는 것
  modifiableFactors: string[];    // 줄일 수 있는 것
  seeDoctor: string;
  urgent?: boolean;
  note?: string;
};
```

## UI 지시

```
"임상 노트" 카드를 상세 백과로 확장.
docs/content/conditions_part1_heart_v2.md 기준. (v1 문서가 있으면 무시)

[데이터]
1. app/i18n/conditions/ko.ts 신규 생성
2. ConditionDetail 타입은 문서 스키마 그대로
   (causes / fixedFactors / modifiableFactors 3개 필드)
3. 기존 organ.conditions(문자열 배열)는 그대로 두고 name으로 매칭
   → 상세가 없는 질환은 목록에만 표시하고 클릭 안 되게

[카드]
4. 카드에는 지금처럼 질환명 목록. 상세가 있는 항목엔 누를 수 있다는 표시
5. "전체 보기" → 그 장기의 전체 질환 목록 모달

[상세 화면]
6. 질환을 누르면 상세가 열림. 구성 순서:
   - 이름 + 한 줄 요약
   - urgent가 true면 상단에 눈에 띄는 배지
   - 어떤 병인가 (what)
   - 주요 증상 (symptoms, 목록)
   - 왜 생기나 (causes)
   - 위험 요인 — 두 칸을 나란히:
       "바꿀 수 없는 것" (fixedFactors)
       "줄일 수 있는 것" (modifiableFactors)
     ★두 칸의 무게가 같아 보이게. 후자만 강조하면
      "관리 안 해서 걸렸다"로 읽힐 수 있음
   - ★이럴 땐 진료를 (seeDoctor) — 시각적으로 가장 강조
   - 알아두면 좋은 것 (note, 있을 때만)
7. 모달 하단 고정 안내문 (ui/ko.ts에 추가):
   "이 내용은 교육 목적의 일반 정보입니다.
    증상이 있거나 걱정된다면 의료진과 상의하세요."

[제한]
8. 어린이 모드에서는 임상 노트 카드 자체를 숨길 것
9. TTS 적용하지 말 것

[검증]
10. 심장 8개가 전부 열리는지, seeDoctor·fixedFactors·
    modifiableFactors가 모두 있는지, urgent 배지가 4건
    (관상동맥질환·심부전·심근염·심방세동)에 뜨는지 확인

커밋 파일별 명시 (git add -A 금지).
```
